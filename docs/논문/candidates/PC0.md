# PC0 / 기존 멀티모달 열화 분류의 실제 기여 정리

- **상태:** `DESIGNED` — 확정 오류는 본문 정정 완료(2026-09-07), 재실험 의존 4건 보류.
- **산업 문제와 필요한 의사결정:** AI Hub 열화 4단계 분류 원고를 제출할 수 있는 상태로 만들 것인가,
  아니면 현장 연구(PC1)로 자원을 옮길 것인가. 결정에는 "이 원고가 실제로 무엇을 보였는가"의
  정직한 목록이 필요하다.
- **한 문장의 핵심 주장 (검증 상태 표시):** *가설* — 도메인 정보를 넣은 경량 LSTM이 동일 프로토콜
  아래 공급자 공식 아키텍처(V1) 대비 macro F1을 개선한다. **이 주장 자체는 저장된 결과가
  지지한다**(V2+ 0.9557 ± 0.0006 vs V1 0.9235, 동일 split·라벨·정규화). 다만 원고의 현재
  비교·판정 서술 다수가 정정을 요한다.
- **가장 가까운 선행 연구와 차이:** 공급자 공식 모델은 **Multimodal LSTM+CNN**이며 Transformer가
  아니다(`best_model.pth` state_dict에 attention 텐서 0개). 우리 V1이 같은 아키텍처
  (파라미터 2,833,412 일치). 따라서 차이는 "Transformer 대비 경량"이 아니라 **동일 백본에
  시간차분·채널 attention·SupCon을 더한 효과**다.
- **기존 방법이 실패하는 구체적 조건:** Normal↔Mild 경계. V1 NM 57 → V2 45 → V2+ 24~33.
- **제안 방법의 최소 구성:** V2(single-lag) + multi-scale 차분[1,5,10] + SE + SupCon.
- **필요 데이터와 현재 확보 수준:** AI Hub 111,870 샘플. **현재 `extracted/`가 0바이트로
  재학습 불가**(blocker B-1). 684 zip 재추출 필요. 결과 JSON 16개·checkpoint는 보존됨.
- **필수 기준선·ablation·반례:**
  - V1(공식 아키텍처) — 확보
  - V2 single-lag — 확보
  - 2³ ablation 동일 예산·다중 seed — **미실행**(`EXP-20260907-003`)
  - 공식 TimesNet 구현 — **미실행**(`EXP-20260907-004`)
  - 장비 그룹 K-fold + val 동결 — **미실행**(`EXP-20260907-006`)
- **주장별 연결된 실험 ID:** [claim_evidence.csv](../claim_evidence.csv) CE-001~CE-046.
- **확보된 그림/표:** Table 6~15, Figure 1~6. **필요한 것:** 동일 예산 ablation 표,
  Jetson 실측 지연 표, 장비 단위 불확실성 표.
- **기각·축소 조건:**
  - 2³ 재실행에서 결합 이득이 예산 효과로 대부분 설명되면 "synergy" 기여를 철회한다.
  - AI Hub 데이터를 복구하지 못하면 재실험 의존 정정을 완료할 수 없으므로 원고를
    "현행 근거 범위"로 축소 제출하거나 보류한다.
- **다른 후보와 중복/통합:** 없음. PC1~PC4는 현장 데이터 기반으로 독립.
- **현재 상태와 다음 승격 조건:** `DESIGNED`. `PILOT` 승격 조건 = B-1 해소 + `EXP-20260907-002/003`
  완료. 상세 근거는 [연구노트 #16](../../연구노트/연구노트_16_외부검토_실측검증.md) §3.
