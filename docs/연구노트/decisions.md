## D-003 · A안(현재 실측을 기존 8채널에 그대로 투입) 제외 — ACTIVE

- **결정:** 현재 실측을 legacy 8채널 모델에 그대로 넣는 A안을 실행 후보에서 제외한다.
- **대안:** 재정규화 후 legacy 가중치 재사용 → 학습된 가중치의 의미가 유지되지 않는다.
- **근거:** 연구노트 #16 §5.1 — thermal legacy 30.98~146.10 °C vs 현장 23.73~38.08 °C
  (입력 span의 12.5%, 하단 음수), scalar z −0.33~−1.58. CT2~4 물리 부재는 별개 문제.
- **주장 범위:** 정규화 불일치만으로 **미래의 모든 8채널 설계가 불가능하다고 단정하지 않는다.**
  known-load CT1 확보가 CT2~4 부재를 해결하지도 않는다.
- **재검토 조건:** 부하가 걸린 CT 실측 확보 시. **최종 입력 설계 결정은 G1-S 이후 handoff §11.**

- **근거:** 연구노트 #16 §3.1~3.2. claim_evidence CE-002/CE-003/CE-004.

## D-014 · 추가 baseline 실행 여부 — OPEN (연구 결정)

- **미결 사항:** cross-attention의 상한 여부를 실제로 검증할 것인가. 검증하려면 독립 구현
  (외부 cross-attention 멀티모달 모델) 또는 CATFT를 동일 튜닝 예산에서 재탐색해야 한다.
- **대안:** (a) 검증하지 않고 "우리 프로토콜에서 관측된 결과"로만 서술 — 현재 적용 상태.
  (b) 독립 구현을 추가 실행해 상한 주장을 재시도. (c) 공식 TimesNet 구현만 정리하고
  cross-attention 논증은 폐기.
- **필요 입력:** 연구 우선순위 판단. 비용은 B-1(AI Hub 데이터) 해소 후의 GPU 시간.
- **D-005와의 관계:** D-005는 사실 정정이므로 이 결정과 무관하게 이미 적용됐다. 이 항목은
  "무엇을 더 실행할지"만 다룬다.

## D-006 · 국소 결함 수정은 즉시 적용, 학습·통합 검증만 gate 이후 — ACTIVE (2026-09-07 정정)

- **정정 이력:** 초판은 "코드 적용도 G1-S 이후"로 정했다. **과도했다.** handoff §10 STOP boundary가
  금지하는 것은 `training / model schema modification / ONNX export / TensorRT / CT imputation /
  anomaly threshold generation / raw mutation` 일곱 가지이며, **주기 계산식 오류나 seed 설정 순서
  같은 국소 결함 수정은 그 목록에 없다.** 데이터가 없다는 이유로 허용된 작업까지 막지 않는다
  (업무 지침 §4 마지막 문단).
- **결정:** 다음을 구분한다.
  - **즉시 적용(완료):** F04 TimesNet 주기식, F03 seed 순서·`--seed`·초기 가중치 hash,
    F14a eval autocast 조건부화. 모두 되돌릴 수 있는 국소 수정이며 정적·산술 검증을 통과했다.
  - **적용 보류(설계 결정):** F14b 이중 보정 제거는 sampler/CE 중 무엇을 남길지가 실험으로
    결정할 사안이므로 단독 수정하지 않는다 → `EXP-20260907-007`.
  - **적용 보류(금지 목록 해당):** F09 trial 스키마 개명은 acquisition 스키마 변경이므로
    G1-S 및 별도 승인 이후. F10은 ModelAdapter가 아직 없어 대상 코드가 없다(요구사항으로 기록).
  - **미실행:** torch가 필요한 통합 검증(실제 재학습으로 수정 전후 비교) → G1-S + G2d 이후.
    **검증되지 않은 실행 성공을 주장하지 않는다.**
- **근거:** handoff §10 원문 대조. 연구노트 #16 §10 LV-1~LV-6.
- **재검토 조건:** 재실행 결과가 나오면 수정 영향을 기록한다.
