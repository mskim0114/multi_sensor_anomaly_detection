## 1. MCP 플러그인 관련

### 1.1 HuggingFace MCP 연결 실패
- **발생:** 2026-03-20
- **증상:** `huggingface: npx -y @huggingface/mcp-server - ✗ Failed to connect`
- **원인:** npm 패키지명 `@huggingface/mcp-server`가 존재하지 않음 (404)
- **해결:** `uvx huggingface-mcp-server`로 변경 후 정상 연결
- **명령어:** `claude mcp add huggingface -s user -e HF_TOKEN=... -- uvx huggingface-mcp-server`

### 1.2 Node.js 버전 너무 낮음
- **발생:** 2026-03-20
- **증상:** conda 기본 nodejs가 v12.4.0으로 설치됨
- **해결:** `conda install -c conda-forge 'nodejs>=18' -y` → v24.10.0 설치

### 1.3 GitHub MCP 환경변수 설정 오류
- **발생:** 2026-03-20
- **증상:** `-e` 플래그가 `--` 뒤에 들어가서 npx 인자로 전달됨
- **해결:** `-e`를 `--` 앞에 배치: `claude mcp add github -s user -e GITHUB_PERSONAL_ACCESS_TOKEN=... -- npx ...`

## 2. matplotlib GUI 관련

### 2.1 headless 환경에서 GUI 백엔드 불가
- **발생:** 2026-04-06
- **증상:** `ImportError: Cannot load backend 'Qt5Agg' which requires the 'qt' interactive framework, as 'headless' is currently running`
- **원인:** Claude CLI 세션은 headless (DISPLAY 환경변수 없음)
- **해결:** 
  - `os.environ.get("DISPLAY")` 체크 후 GUI/Agg 백엔드 자동 선택
  - headless 환경에서는 `--save-dir`로 이미지 파일 저장
  - 사용자가 터미널에서 직접 실행하면 GUI 정상 작동

### 2.2 TkAgg 백엔드 없음
- **발생:** 2026-04-06
- **증상:** `ImportError: Cannot load backend 'TkAgg'`
- **해결:** PyQt5 설치 (`pip install PyQt5`) 후 Qt5Agg 사용

- **발생:** 2026-03-24 (분석 시 발견)
- **증상:** sliding window(step=1) + random split → train/test에 29/30 겹치는 윈도우 분산

## 4. 모델 학습 관련

### 4.1 CATFT 학습 불안정
- **발생:** 2026-04-06
- **증상:** Epoch 8, 11에서 val F1이 0.71, 0.65로 급락 후 회복
- **원인:** EfficientNet backbone fine-tuning 시 학습률이 너무 높아 가중치 급변
- **해결 방안:**
  - backbone freeze layer 늘리기 (5 → 7)
  - warmup scheduler 적용
  - 더 낮은 초기 학습률 (5e-4 → 2e-4)
- **현재 상태:** 30 에폭 학습 시 후반에 안정화되어 F1=0.9252 달성. 치명적이진 않지만 개선 여지 있음

### 4.2 Transformer 과적합 (V4)
- **발생:** 2026-04-06
- **증상:** V4(CATFT-NoCrossAttn)가 V1(Baseline)보다 F1 낮음 (0.9112 vs 0.9235)
- **원인:** 9,313개 학습 윈도우 대비 Transformer(7.6M params)가 과한 용량
- **교훈:** 데이터 규모에 맞는 모델 복잡도 선택 중요. LSTM(2.8M)이 현 데이터 규모에 적합

## 5. 환경/인프라 관련

### 5.1 센서 사양 불일치 (사전 방지)
- **발생:** 2026-03-24 (데이터 분석 시 발견)
- **내용:** 기존 구매 가이드에서 전류 센서를 SCT-013(30~50A)으로 추천했으나, 실측 CT2 최대값이 273.91A
- **해결:** SCT-024(400A)로 상향 조정, 구매 가이드 문서 업데이트 완료
- **교훈:** 센서 구매 전 반드시 데이터셋 실측 범위 확인

### 5.2 FLIR Lepton 온도 범위 경계
- **발견:** 2026-03-24
- **내용:** 열화상 실측 최고 146.10°C → Lepton 3.5 기본 모드(-10~140°C) 초과
- **해결:** High Gain/Low Gain 모드 전환으로 대응 가능 (센서 도착 후 설정)
- **상태:** 미해결 (센서 미도착)
