## 3. 해석 — 가설은 지지되지 않았다

**정정.** 뽑기 2회만 봤을 때 "같은 예산이면 8대가 1대보다 +19.9 pp" 이고 "다양성(+20)이 양(+16)보다 중요하다" 고 중간 보고했다.
뽑기를 4회로 늘리자 **두 수치가 모두 바뀌었다.** 아래가 확정값이다.

```
같은 예산, 1대 → 8대            +12.26 pp   (2회 표본에서는 +19.91)
같은 8대에서 예산 8배           +20.66 pp
1대 240창 → 8대 2,332창 전체    +32.91 pp
  그중 다양성 +12.26 pp,  양 +20.66 pp   →  양이 더 크다
```

**관찰.**
- **양이 지배 요인이다.** 같은 8대에서 창을 8배 늘리면 +20.7 pp 인데, 같은 예산에서 장비를 8배 늘리면 +12.3 pp 다.
- macro F1 의 장비 수 순서는 **해소되지 않았다.** 2·4·8대의 평균이 0.648 / 0.696 / 0.672 인데 각 점의 std 가 0.031~0.129 다.
  1대와 8대의 차이(+12.3 pp)는 표준오차(약 5 pp)의 2배 남짓이라 방향은 보이되 크기는 확정할 수 없다.
- **Severe recall 은 깨끗하다.** 0.617 → 0.883 → 0.905 → 0.928 로 장비 수에 따라 단조 증가하고, **파국적인 뽑기(0.409)가 나오는 것은
  1대 조건뿐**이다. 안전 지표에서는 장비를 나누는 쪽이 분명히 낫다.
- **250창에서는 아무것도 안정되지 않는다.** 전 조건에서 뽑기별 F1 이 0.15~0.28 폭으로 흩어진다.

**추론(미검증).** 뽑기 폭의 원인으로 학습셋의 클래스 구성을 의심했으나 설명되지 않았다. 1대 조건에서 Normal 비중 50 % 인 두 뽑기가
F1 0.587 과 0.667 로 갈리고, 4대 조건에서는 Normal 57 % 인 뽑기가 0.754 로 41 % 인 뽑기(0.746)보다 높다. 250창 규모에서는
**세션 하나의 내용**이 지배하는 것으로 보이나 이 데이터로 특정하지 못했다.

**한계.** AI Hub 의 장비·센서·고장은 현장의 것이 아니다. 이 곡선은 **이런 종류의 문제의 형태**이지 현장 정확도의 예측이 아니다.
평가는 validation 4대이므로 장비 단위 불확실성(±0.005, N23)이 위에 더해진다. 점당 seed 1개. AI Hub 는 장비당 약 2시간뿐이라
**"한 대를 60시간"** 조건은 만들 수 없었다 — 그 질문은 현장에서만 답할 수 있다.

## 4. 현장 캠페인에 주는 값 (계획 근거, 보증 아님)

```
장비 1대만  → 쓸 수 없다. F1 0.52, Severe recall 0.51, 어느 장비를 고르냐에 0.13 폭
장비 2대    → Severe 가 잡히기 시작한다 (recall 0.95)
장비 4대    → 뽑기 운이 사라진다 (폭 0.010). 약 1,200창 = 10시간
장비 8대+   → 배가당 +2~3 pp 의 완만한 구간
같은 예산이면 여러 대로 나누는 편이 낫다 — 특히 Severe recall 에서. 다만 양을 늘리는 것이 더 크다
```

가장 실무적인 결론은 **250창(2시간)은 어떤 배치로 나눠도 결과가 의미를 갖지 못하는 규모**라는 것이다.
현재 Jetson 누적이 정확히 그 규모(240창)이며, 게다가 전부 정상이고 라벨이 없다(N26).
