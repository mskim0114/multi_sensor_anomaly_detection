## 0. 2026-07-31 Addendum — 데이터 스키마 실체 확인 (매우 중요)

사용자가 제공한 **데이터 스키마 명세** 로 S## 코드 → 실제 센서 모델 매핑을 확정하고, 20,000 샘플 검증을 수행한 결과 다음을 새로 발견함:

### A. 실사용 센서 확정 (단일 sensor set, heterogeneous 아님)

이전에 "S02/S04/S06/S08 4종을 섞어 heterogeneous 하게 수집" 이라고 추정했으나, 실측 결과 **전 데이터의 100% 가 동일한 1종씩** 사용:

Sensor diversity 는 없지만 device diversity 는 있음.

### C. 열화상 upsampling 확인 (모델 spatial feature 상한)

TeraRanger Evo Thermal 33 = **32×32 native 해상도** (1,024 픽셀). 저장 포맷 120×160 은 여기서 **약 15× 업샘플링**된 결과.

- 우리 CNN 이 학습한 spatial feature 는 실질적으로 32×32 정보에 상한
- **논문 Section 6.5 "thermal 기여도 +0.37%" 의 잠재 원인**: 원본 해상도 상한 때문에 upsampled 120×160 에서 추가 학습 여지 제한
- 실배포용 FLIR Lepton 3.5 (160×120 native, 19,200 픽셀) 는 학습 분포보다 정보 풍부 → downsample or fine-tune 필요

### D. BIN 파일 실체 검증

- 파일 크기 153,728 bytes
- 구조 = **128-byte 헤더 + 120×160 float64 (°C)**
- 이전 문서에 "float64 (120×160)" 만 서술했으나 헤더 존재 확인

## 0-2. 2026-07-31 저녁 Addendum — AI Hub 활용 가이드라인 문서 발견

사용자가 저녁에 추가로 제공한 **AI Hub 데이터 활용 가이드라인 요약** 으로 다음 결정적 사실 5가지 확인:

### A2. 총 세트 수 확정 · 우리는 subset

- **원본 총 124,263 세트** (OHT 73,733 / AGV 50,530)
- 우리 보유 111,870 세트 = 원본의 **~90% subset** (Training 99,476 + Validation 12,394)
- 12,393 세트 미포함 (아마 별도 test set 또는 미공개)

### B2. Sampling 실체 확정

- **원본 raw = 100 ms 주기 (10 Hz)** 센서 수집
- **Dataset provider 가 1 s 단위로 aggregation 후 배포**
- 각 JSON 파일 = 1초 단위 스냅샷 1개 (센서 값 1개씩)
- **Aggregation 방식(mean/max/last) 불명** — dataset provider 미공개

즉 우리가 학습한 데이터는 이미 시간축으로 **10× downsampling** 된 것.

### C2. 4-Class 라벨 정확 정의 (§0-G 초안 확장)

**정확한 라벨 정의 (문서 확정)**:

| state | 정의 | 물리적 의미 |
|:---:|:---|:---|
| **0 정상** | Z-score ≤ 3.5 | 정상 (원본의 **약 99%**) |
| **1 관심** | Z-score > 3.5 시점 ~ GT-30s 직전, **전반부 50%** | 이상 초기 |
| **2 경고** | Z-score > 3.5 시점 ~ GT-30s 직전, **후반부 50%** | 이상 후기 |
| **3 위험** | **GT-30s ~ GT** (탄화 발생) | 마지막 30초 |

**GT = Ground Truth (실제 탄화 발생 시점)**.

**⚠️ 매우 중요**: 관심(1) ↔ 경고(2) 는 **같은 구간을 임의 1:1 분할한 것** (문서 명시: "AI 서비스 예지보전 민감도 조정용"). 즉 두 클래스의 boundary 는 **물리적 · 통계적 의미 없음**. 완벽 구분 불가능 → 우리 논문 Section 6.3 (N↔M 오류 47% 감소) 재해석 필요.

### D2. 원본 정상 99% → 우리는 balanced subset

우리 검증 데이터 실측:
- 정상 49.35% / 관심 21.59% / 경고 21.39% / 위험 7.66%

**즉 우리 111,870 은 원본에서 정상 클래스를 대폭 downsampling 한 balanced subset**. 실배포는 원본과 유사한 99% 정상 분포 → **domain gap 존재**. 논문 Section 7.5 (Limitations) 에 명시 필요.

### E2. AI Hub 참조 baseline MMTransformer 성능

- **아키텍처**: ViT (이미지 patch embedding) + 시계열 encoder + **Cross-Attention Mechanism**
- **성능**: **Accuracy 91.92% / F1 91.09%** (목표 0.80 / 0.68 초과)
- **우리 V2+ 대비**: **+3.10 %p Acc, +4.48 %p F1** 명확히 능가

이 결과는 우리 논문에 **매우 강력한 empirical 근거** 로 추가 가능:
- 동일 dataset · 동일 라벨 정의 · 공식 baseline
- **Cross-Attention 계열은 이 dataset 에서 ~91% F1 상한** → 우리 CATFT V5 (0.9252) 도 유사 수준
- Domain-informed lightweight 접근 (LSTM + multi-scale diff + SE + SupCon) 이 architectural complexity 를 이김

### F2. CT 채널 의미 확정

- **CT1 = 입력단**, **CT2 = 출력단**, **CT3 = 모터1**, **CT4 = 모터2**

지금까지 우리 논문·연구노트는 "CT1~CT4" 로만 서술했으나 **위치·역할이 명확히 다름**. Section 3 (Sensor Specifications) 에 반영.

### G2. 사전 정제 규칙

Dataset provider 가 이미 수행:
- Numpy 통계 기반 이상치 색인·제거
- 파일 유사도 95 이상 제거 (센서: 상관도 + 가중치, 열화상: VisiPics)

→ 우리가 별도 outlier removal 안 해도 되는 근거. 논문 Section 3 (data pipeline) 방어 논리.

### 4.3 핵심 패턴 해석

1. **온도(NTC):** 열화 단계와 **선형적 상관관계**. 정상(27°C) → 중증(51°C), 약 24°C 상승. 가장 안정적인 지표.
2. **미세먼지(PM):** State 0→2까지 점진적 증가 후 **State 2~3에서 포화**. 초기 열화 감지에 유용하나 중증 구분에는 한계.
3. **전류(CT):** State 0~1은 비슷하다가 **State 2~3에서 급격히 증가**. 특히 State 3에서 폭발적 증가. 중증 열화 감지의 핵심 지표.

**모델링 시사점:**
- NTC는 전 단계에서 유용한 **범용 지표**
- PM은 **초기 이상 감지** (State 0→1 전이)에 유용
- CT는 **중증 이상 감지** (State 2→3 전이)에 결정적
- 3종 이상상태와의 매핑: 열적 과부하(NTC 주도), 탄화/연기(PM 주도), 전기/기계 결함(CT 주도)이 데이터로 뒷받침됨

## 5. 열화상 이미지 통계

| 항목 | 값 |
|------|-----|
| 저장 shape | 모두 (120, 160) |
| **네이티브 소스 해상도** | **32×32** (TeraRanger Evo Thermal 33, §0-C 참조) |
| **업샘플링 배율** | 약 15× (32×32 → 120×160) |
| 온도 Min 범위 | 30.98 ~ 44.75 °C |
| 온도 Max 범위 | 35.19 ~ **146.10 °C** |
| 온도 Mean 범위 | 33.03 ~ 56.67 °C |
| 파일 실체 | **128B 헤더 + 120×160 float64** (총 153,728 bytes) |

**관찰:** 최고 온도가 146.10°C까지 올라감 → 심각한 열적 과부하 상태를 포착하는 데이터 존재.

**중요 (2026-07-31 확인):** 저장 shape (120×160) 은 처리 포맷일 뿐, 원본 센서는 **32×32 native**. CNN 이 학습할 수 있는 spatial 정보는 실질적으로 32×32 수준에 상한. 이는 논문 Section 6.5 (thermal contribution +0.37%) 의 잠재적 원인 중 하나.

## 8. 데이터 품질 평가

**장점:**
- 대규모 (111,870 샘플), 논문 수준의 실험에 충분
- 장비 단위 train/val 분리 → 일반화 성능 평가 가능
- 상태별 센서 패턴이 명확 → 모델 학습 가능성 높음
- 모든 BIN 파일이 동일 shape (120×160) → 전처리 일관성

**주의사항:**
- State 3 비율 ~8% → 클래스 불균형 대응 필요 (Focal Loss, oversampling 등)
- 전류 센서 스케일 편차 큼 → 센서별 정규화 필수
- PM 센서 State 2~3 포화 현상 → 단독으로는 중증 구분 어려움
- CSV가 1행 데이터 → 시계열 구성 시 파일 단위 로딩 필요 (I/O 병목 가능)
