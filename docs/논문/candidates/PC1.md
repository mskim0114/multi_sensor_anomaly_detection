# PC1 / 관계 기반 현장 이상 탐지

- **상태:** `IDEA` — 현장 이상 데이터가 없어 설계 단계도 확정할 수 없다.
- **가설 ID:** `FIELD-HA`
- **산업 문제와 필요한 의사결정:** 로봇 셀에서 정상 운전 변화(부하 전환·속도 변경)와 실제 이상을
  구분해야 한다. 작업자는 경보를 받으면 무엇을 점검할지 결정해야 한다.
- **한 문장의 핵심 주장 (검증 상태 표시):** *가설, 미검증* — 같은 입력 채널·연산 예산·오경보
  기준에서 운전 맥락에 조건화된 **반응 관계**(방향·시차·회복)가 센서별 독립 표현의 가산 결합보다
  사건 검출률 또는 선행시간을 개선한다.
- **가장 가까운 선행 연구와 차이:** 공정 감시·시스템 식별·변화점 탐지·도메인 일반화 문헌과 좁혀
  비교해야 한다(업무 지침 §9). **아직 3~5개 비교표를 작성하지 않았다.** "관련 연구를 찾지 못함"을
  신규성 근거로 쓰지 않는다.
- **기존 방법이 실패하는 구체적 조건:** 진폭이 정상 변화와 겹치는 이상. 현재 V2+는 구조적으로
  이 구분을 할 수 없다 — 열화상 시간축이 평균으로 붕괴되고 융합이 선형 가산이다
  (연구노트 #16 §5.2, claim_evidence CE-042).
- **제안 방법의 최소 구성:** 업무 지침 §6의 B0 → B1 → B2 → B3 → M1 순서. M1은 B3 대비 이득이
  확인된 뒤에만 만든다. B3는 **legacy 구조(LSTM 128×3 + 프레임 CNN + 시간평균 + 가산 결합)의
  5채널 변형**으로 정의해야 "기존 결합 방식"의 공정한 기준점이 된다.
- **필요 데이터와 현재 확보 수준:**
  - 정상 운전 다양성: **5 trial 30분뿐**. 부하·속도·작업·주변환경·장착위치·장비·날짜 변화 없음
  - 확인된 이상 현상: **0건**
  - 진폭이 겹치는 정상/이상 대조: 0건
  - sham control: 0건
- **필수 기준선·ablation·반례:** 단일 센서 / 정적 요약 / 가산 결합 / 시간 순서 제거 /
  센서 간 시간 정렬 교란 / 같은 크기 정상 변화 / 운전 조건만으로 예측하는 기준선.
  시간 교란은 비현실적 입력을 만들 수 있으므로 실제 대응 trial에서도 검증한다.
- **주장별 연결된 실험 ID:** `EXP-20260907-005`(열화상 병목 분리, legacy 데이터 기준).
  현장 실험은 미등록 — G3 이후.
- **확보된 그림/표:** 없음. **필요:** 관측 가능성 확인표, 사건 단위 평가표, 반례 실험표.
- **기각·축소 조건:** 개선이 진폭 차이, 시험 시작 후 경과시간, 특정 설치 위치, 특정 장비
  식별로 설명되거나 새 날짜·설비에서 사라진다. 관측 관계만으로 원인을 증명했다고 쓰지 않는다.
- **다른 후보와 중복/통합:** PC2는 이 후보의 필수 구성요소일 수 있다. 독립 질문·독립 증거가
  확보되지 않으면 PC2를 PC1에 합친다.
- **현재 상태와 다음 승격 조건:** `IDEA`. `DESIGNED` 승격 조건 = G3(현장 문제 정의) 완료 +
  선행 연구 3~5개 비교표 작성 + 이상 유발 절차가 로봇 소유기관과 확정.

**경계.** B0와 정상 기반 탐지는 G1-S 및 입력 검토 경계 이후에만 실행한다. no-load CT1을
정상 운전 기준·threshold 적합에 쓰지 않는다(decisions.md D-009).
