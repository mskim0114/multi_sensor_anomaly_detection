# PC2 / 관측 품질과 판단 가용성

- **상태:** `IDEA`
- **가설 ID:** `FIELD-HB`
- **산업 문제와 필요한 의사결정:** 센서가 일시적으로 관측을 잃을 때(FFC, 통신 오류, 장기 누락)
  시스템이 침묵할지, 부분 관측으로 판정할지, 판단 보류를 표시할지 결정해야 한다.
- **한 문장의 핵심 주장 (검증 상태 표시):** *가설, 미검증* — 실제 FFC·센서 부재 조건에서 품질을
  고려한 모델 또는 검증된 sensor-only 경로가, 완전 윈도만 요구하는 방식보다 동일 오경보·미탐
  제약 아래 **유효 판정 시간**을 늘린다.
- **가장 가까운 선행 연구와 차이:** 센서 결함 진단·결측 하 학습·abstention 문헌과 비교표 필요.
  미작성.
- **기존 방법이 실패하는 구체적 조건:** 현재 정책은 30-tick 창에 thermal invalid tick이 하나라도
  있으면 창 전체를 버린다. 이 손실은 **무작위가 아니다.**
  ```
  stale tick   seq 28~31 과 211~214 두 군데에만 집중
  trial 내     window index 0: 2/5   1: 4/5   7: 5/5
  canonical 개입 구간 90~269 와 seq 211~214 가 겹친다
  ```
- **제안 방법의 최소 구성:** 값 + 관측 시각 + age + status + 실제 가용 센서를 함께 다루고,
  전체 신뢰 / 부분 관측 제한 판정 / 판단 불가 세 상태를 구분하는 정책.
- **필요 데이터와 현재 확보 수준:**
  - 실제 센서 품질 저하: v1 baseline에 FFC 사례 **있음** (13/1800 tick, 11/60 window)
  - 통신 오류: SCD30 polling error 2건 (window invalidation 조건 아님)
  - 장시간 누락: 0건
  - 이상 사건과 품질 저하가 겹치는 사례: **0건**
- **필수 기준선·ablation·반례:** 현재 완전 윈도 기준 / 모델별 필수 입력 검사 /
  사전 검증한 부분 입력 모델. random dropout만으로 평가하지 않고 실제 FFC 구간과 연속 오류를
  시간축 그대로 포함한다.
- **주장별 연결된 실험 ID:** 미등록 — 현장 모델(B0~B3) 이후.
- **확보된 그림/표:** v1 윈도 유효율과 stale tick 분포(연구노트 #16 §5.4).
  **필요:** coverage-detection trade-off 곡선, 조건별 미탐 표.
- **기각·축소 조건:** 품질 변수가 시나리오의 대리 라벨로만 작동하거나, 경보를 줄인 만큼 관측
  포기 시간이 늘어 실제 효용이 개선되지 않는다. 보류율을 높여 정확도만 좋아 보이게 만드는 것도 실패.
- **다른 후보와 통합 가능성:** PC1에 필수적인 한 요소로 판명되면 합친다.
- **현재 상태와 다음 승격 조건:** `IDEA`. `DESIGNED` 승격 조건 = 사건 라벨 확보 +
  개입 타이밍이 다른 검증 trial과 sham control이 별도 protocol version으로 승인.

**지표 표기.** `49/60 = 81.7 %`는 **v1 윈도 유효율**이다. 판단 가용률로 환산하지 않는다.
판단 가용률은 경보를 내는 현장 모델이 없어 계산 불가(decisions.md D-008).

**정책 경계.** v1 품질 정책은 변경하지 않는다. FFC manual 전환, post-FFC exclusion rule 추가,
interpolation, stale frame 대체 모두 금지이며 v1 자료를 재라벨링하지 않는다.
