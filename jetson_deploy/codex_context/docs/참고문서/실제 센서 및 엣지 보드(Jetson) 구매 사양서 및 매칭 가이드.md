# 실제 센서 및 엣지 보드(Jetson) 구매 사양서 및 매칭 가이드

본 보고서는 AI Hub의 **"제조현장 이송장치의 열화 예지보전 멀티모달 데이터"** [1] 규격과 **원본 데이터셋 111,870 샘플 분석 결과**를 바탕으로, **3종 이상상태 예측** 목표에 최적화된 **실제 센서 및 엣지 보드(Jetson) 구매 사양서**를 제공합니다.

> **2026-03-26 업데이트:** 원본 데이터셋(Training 99,476 + Validation 12,394 샘플) 전수 분석 결과를 반영하여, 센서 측정 범위 및 모델 선정을 수정하였습니다. 특히 **전류 센서(CT)의 최대값이 273.91A**로 확인되어 기존 추천(SCT-013, 30~50A)에서 **400A급(SCT-024)으로 상향 조정**하였습니다.

| **형태** | 링 터미널형 또는 비드형 (설비 표면 부착 가능) |

### 2.3 전류 센서 (CT, 4채널)

| 항목 | 사양 |
| :--- | :--- |
| **추천 모델** | **YHDC SCT-024-000 (400A)** × 4개 |
| **타입** | 비접촉식 분할코어 전류 트랜스포머 (클램프형) |
| **측정 범위** | 0~400A (실측 최대 273.91A 대비 **약 30% 여유**) |
| **출력** | 아날로그 AC 전류 (0~50mA, 비율 1:8000) |
| **코어 내경** | 24mm |
| **정밀도** | ±1~2% |
| **예상 가격** | ₩8,000 ~ ₩15,000/개 × 4 = **₩32,000 ~ ₩60,000** |
| **구매처** | AliExpress ("YHDC SCT-024"), Devicemart, Mouser |

> **⚠️ 주의: 기존 추천이었던 SCT-013-000 (30~50A)은 사용 불가.**
> 데이터 분석 결과 CT2 최대값이 **273.91A**로 확인되어, 100A 이하 센서는 클리핑이 발생합니다.
> 반드시 **400A급 이상** 센서를 사용해야 합니다.

**대안 모델:**
- **CR Magnetics CR3110-3000** (0~300A, 고정밀): ~$25-40 USD, Mouser
- **YHDC SCT-019-000** (0~200A): CT1/CT4에만 사용 가능 (CT2/CT3에는 부족)

**신호 조건화 회로 필요:**
- CT 출력(AC 전류) → Burden Resistor → DC Bias(1.65V) 추가 → ADS1115 입력 (0~3.3V)
- 4채널 CT + 1채널 NTC = 5채널 → **ADS1115 2개 필요** (I2C 주소 0x48, 0x49)

### 2.4 열화상 카메라

| 항목 | 사양 |
| :--- | :--- |
| **추천 모델** | **FLIR Lepton 3.5** (P/N: 500-0771-01) + Breakout Board |
| **해상도** | **160 × 120 픽셀** (AI Hub 데이터 120×160과 **정확히 일치**) |
| **스펙트럼** | 8~14 µm (LWIR) |
| **온도 범위** | -10°C ~ +140°C (기본), Radiometry 모드에서 +450°C 확장 |
| **출력** | **14-bit 픽셀별 원시 온도값** (Radiometric) |
| **인터페이스** | **SPI** (영상 데이터) + **I2C** (제어, 주소 0x2A) |
| **프레임 레이트** | 8.7 Hz |
| **정밀도** | ±5°C 또는 ±5% |
| **예상 가격** | ₩250,000 ~ ₩350,000 (모듈) / ₩350,000 ~ ₩450,000 (브레이크아웃 포함) |
| **구매처** | **GroupGets** (공식 유통), SparkFun, DigiKey, Mouser |

> **⚠️ 반드시 Lepton 3.5를 구매해야 합니다.**
> - **Lepton 3.0**: 160×120이지만 Radiometry 미지원 → 픽셀별 온도값 출력 불가 (이미지만 출력)
> - **Lepton 3.5**: 160×120 + Radiometry 지원 → **픽셀별 °C 온도 배열 출력** (데이터셋과 동일)
> - **Lepton 2.5**: 80×60 해상도 → 데이터셋과 불일치
>
> 실측 열화상 최고 온도가 **146.10°C**이므로, 기본 모드(-10~140°C) 경계에 있습니다.
> High Gain 모드 또는 Radiometry 확장 모드 설정이 필요할 수 있습니다.

**브레이크아웃 보드 옵션:**
- **FLIR Lepton Breakout Board v2.0** (GroupGets/SparkFun): SPI 직결, 가장 권장
- **PureThermal Mini/3**: USB-C 인터페이스, 프로토타이핑에 편리

## 7. 구매 시 주의사항

1. **전류 센서 용량 확인**: CT2 채널 최대 273.91A 실측 → 반드시 **300A 이상** 센서 필요. SCT-013(100A 이하)은 **사용 불가**.
2. **FLIR Lepton 버전 확인**: 반드시 **3.5** (Radiometric). 3.0은 온도값 출력 불가, 2.5는 해상도 불일치.
3. **열화상 온도 범위**: 실측 최고 146.10°C → Lepton 3.5 기본 모드(-10~140°C) 경계. High Gain 모드 설정 또는 Low Gain 모드(-10~450°C) 전환 필요할 수 있음.
4. **FLIR Lepton 수출 규제**: ITAR(미국 수출 규제) 대상이 아닌 버전인지 확인. 한국 배송 가능 여부를 GroupGets/DigiKey에서 사전 확인.
5. **ADS1115 2개 필요**: NTC(1ch) + CT(4ch) = 총 5채널이므로, 4채널 ADC 1개로는 부족.
6. **PM 센서 위치**: 설비 배기구 또는 탄화 발생 예상 지점 근처에 설치해야 초기 이상(State 0→1) 감지 효과 극대화.
