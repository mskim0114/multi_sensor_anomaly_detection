# 실시간 추론 시스템 구축 및 연구 전략 로드맵

본 보고서는 AI Hub의 **"제조현장 이송장치의 열화 예지보전 멀티모달 데이터"** [1]를 활용하여 **3종의 이상상태(열적 과부하, 탄화 및 연기 발생, 전기적/기계적 결함)**를 예측하고, 실제 작업장에서 **작업자 안전을 보호하기 위한 실시간 추론 시스템 구축 로드맵**을 제시합니다. 앞서 제안된 센서 및 엣지 보드 구매 가이드 [2]를 기반으로 합니다.

## 1. 실시간 데이터 파이프라인 설계

효율적인 실시간 추론을 위해서는 센서 데이터 수집부터 모델 입력까지의 데이터 흐름을 최적화해야 합니다.

### 1.1. 데이터 수집 및 동기화 (Data Acquisition & Synchronization)
*   **센서 연결:** 구매한 NTC, SPS30, SCT-013 센서 및 FLIR Lepton 3.5 열화상 카메라를 NVIDIA Jetson Orin Nano에 연결합니다. 아날로그 센서(NTC, SCT-013)는 ADS1115와 같은 외부 ADC 모듈을 통해 Jetson의 I2C 인터페이스에 연결합니다.
*   **데이터 수집 주기:** AI Hub 데이터셋의 `duration_time` (1초)을 참고하여, 모든 센서 데이터를 최소 1Hz 이상의 주기로 수집합니다. 열화상 카메라는 최대 프레임 속도(예: 9Hz)로 수집합니다.
*   **타임스탬프 동기화:** Jetson의 시스템 클럭을 기준으로 모든 센서 데이터와 열화상 이미지에 정확한 타임스탬프를 부여하여 멀티모달 데이터 간의 동기화를 보장합니다. 이는 AI Hub 데이터셋의 `collection_time`과 동일한 방식입니다.

### 1.2. 데이터 전처리 (Data Preprocessing)
*   **센서 데이터 (시계열):**
    *   **결측치 처리:** 선형 보간(Linear Interpolation) 또는 이전 값 채우기(Forward Fill)를 통해 결측치를 처리합니다.
    *   **노이즈 필터링:** 이동 평균(Moving Average) 또는 칼만 필터(Kalman Filter)를 적용하여 센서 노이즈를 제거합니다.
    *   **정규화:** Z-score 정규화 또는 Min-Max 정규화를 통해 모델 입력 스케일을 통일합니다.
    *   **윈도잉:** AI Hub 데이터셋의 시계열 길이를 참고하여 적절한 윈도우 사이즈(예: 60초)로 데이터를 분할하여 모델 입력 형태로 만듭니다.
*   **열화상 이미지 (2D):**
    *   **리사이징:** FLIR Lepton 3.5의 해상도(160x120)를 모델 입력에 맞게 조정합니다.
    *   **정규화:** 픽셀 값을 0~1 범위로 정규화합니다.

## 2. 멀티모달 AI 모델 아키텍처 및 학습 전략

AI Hub 데이터셋의 MMTransformer 구조를 기반으로, 3종 이상상태 예측에 최적화된 모델을 설계하고 학습합니다.

### 2.1. 모델 아키텍처 (MMTransformer 기반)
*   **센서 데이터 브랜치 (1D-CNN + Transformer Encoder):**
    *   **입력:** 전처리된 시계열 센서 데이터 (온도, 미세먼지, 전류).
    *   **역할:** 1D-CNN으로 각 센서의 국소적 특징을 추출하고, Transformer Encoder를 통해 시간적 의존성 및 센서 간의 상관관계를 학습합니다.
*   **열화상 이미지 브랜치 (경량 CNN):**
    *   **입력:** 전처리된 열화상 이미지.
    *   **역할:** MobileNetV3 또는 EfficientNet-Lite와 같은 경량 CNN 모델을 사용하여 이미지에서 열 분포 특징을 효율적으로 추출합니다.
*   **융합 레이어 (Cross-Attention Fusion):**
    *   **역할:** 센서 데이터 브랜치와 이미지 브랜치에서 추출된 특징 벡터를 Cross-Attention 메커니즘을 통해 융합합니다. 이는 두 가지 모달리티 간의 상호작용을 학습하여 예측 정확도를 높입니다.
    *   **출력:** 최종적으로 3종의 이상상태(열적 과부하, 탄화 및 연기 발생, 전기적/기계적 결함) 각각에 대한 확률을 출력하는 다중 분류(Multi-label Classification) 또는 다중 클래스 분류(Multi-class Classification) 레이어를 구성합니다.

### 2.2. 학습 전략
*   **사전 학습 (Pre-training):** AI Hub의 대규모 데이터셋 [1]을 사용하여 위에서 설계한 멀티모달 모델을 사전 학습합니다. AI Hub 데이터셋의 라벨링(정상, 관심, 경고, 위험)을 3종 이상상태 정의에 맞춰 재매핑하여 활용합니다.
*   **전이 학습 (Transfer Learning) 및 미세 조정 (Fine-tuning):** 실제 작업장에서 수집한 소량의 데이터를 사용하여 사전 학습된 모델을 미세 조정합니다. 이는 모델이 실제 환경의 특성을 반영하고 예측 정확도를 높이는 데 필수적입니다.

## 3. 실시간 추론 시스템 구축 및 최적화

Jetson Orin Nano 환경에서 모델을 효율적으로 배포하고 실시간 추론 성능을 확보합니다.

### 3.1. 모델 배포 및 최적화
*   **TensorRT 변환:** 학습된 PyTorch 또는 TensorFlow 모델을 ONNX 형식으로 변환한 후, NVIDIA TensorRT를 사용하여 Jetson Orin Nano의 GPU에 최적화된 추론 엔진으로 빌드합니다. 이는 추론 속도를 극대화하고 전력 효율을 높입니다.
*   **양자화 (Quantization):** FP16 (반정밀도 부동 소수점) 또는 INT8 (정수 8비트) 양자화를 적용하여 모델 크기를 줄이고 추론 속도를 더욱 향상시킵니다. 정확도 손실을 최소화하면서 성능을 극대화하는 것이 목표입니다.

### 3.2. 실시간 추론 및 안전 대응
*   **추론 주기:** Jetson에서 센서 데이터를 실시간으로 수집하고 전처리하여, 모델이 1초 이내에 3종 이상상태를 예측하도록 합니다.
*   **안전 대응 로직:** 모델의 예측 결과(예: 열적 과부하 확률 90%)에 따라 미리 정의된 안전 임계치(Threshold)를 넘어서면 즉시 작업자에게 경고 알림(시각/청각)을 보내거나, 위험 설비의 자동 정지(Interlock) 명령을 내리는 등의 조치를 취합니다.
