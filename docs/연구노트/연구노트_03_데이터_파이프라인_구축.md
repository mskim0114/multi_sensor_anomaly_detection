## 1. 목적

AI Hub 기존 코드의 6가지 문제를 해결하는 PyTorch 데이터 파이프라인 구축:
1. 데이터 누수 (sliding window random split) → 세션 단위 관리
2. 정규화 없음 → Z-score + Min-Max 정규화
3. 라벨 전략 (첫 번째 샘플만) → Majority vote
4. DataLoader shuffle=False → WeightedRandomSampler
5. 클래스 불균형 미대응 → 가중 샘플링 + 클래스 가중치
6. 메모리 비효율 → Lazy loading + mmap

## 4. 기존 코드 대비 개선 사항

| 항목 | 기존 AI Hub 코드 | 새 파이프라인 |
|------|-----------------|-------------|
| 데이터 분할 | Random split (누수) | 세션 단위 (장비별 train/val 분리) |
| 센서 정규화 | 없음 | Z-score (training set 통계) |
| 열화상 정규화 | 없음 | Global min-max → [0,1] |
| 라벨 전략 | 윈도우 첫 번째 | Majority vote |
| 클래스 불균형 | 미대응 | WeightedRandomSampler + class weights |
| 데이터 로딩 | 전체 메모리 적재 (.npy) | Lazy loading + mmap |
| DataLoader | shuffle=False, batch=4 | Weighted sampler, batch=16, workers=4 |
| 열화상 형태 | Flattened (19200,) | 2D 유지 (120, 160) |
| 모델 호환 | LSTM 전용 | 모델 독립적 dict 출력 |
