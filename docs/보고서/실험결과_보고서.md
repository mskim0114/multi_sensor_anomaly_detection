# 멀티모달 센서 이상상태 예측 AI — 실험 결과 보고

---

## 1. 개요

- **목표:** AI Hub "제조현장 이송장치 열화 예지보전 멀티모달 데이터"를 활용하여 장비 이상상태를 4단계(정상/경도/중도/중증)로 예측하는 AI 모델 개발
- **데이터:** 111,870 샘플 (Training 99,476 / Validation 12,394), AGV 18대 + OHT 18대
- **센서:** 온도(NTC), 미세먼지(PM1.0/2.5/10), 전류(CT1~4) + 열화상 카메라(120×160)
- **평가 환경:** Quadro RTX 6000 × 2, PyTorch 2.6.0

---

## 2. 실험 결과

### 2.1 모델 성능 비교

| 모델 | Val F1 (macro) | Val Accuracy | 파라미터 | 학습 시간 |
|:-----|:--------------:|:------------:|:--------:|:---------:|
| Baseline (Multimodal LSTM) | 0.9235 | 91.88% | 2.8M | 12분 |
| LSTM + EfficientNet | 0.9242 | 91.62% | 4.5M | 108분 |
| **LSTM + Temporal Diff** | **0.9430** | **93.52%** | **2.8M** | **12분** |
| CATFT (Cross-Attention Transformer) | 0.9252 | 92.13% | 10.8M | 108분 |
| CATFT − Cross-Attention | 0.9112 | 90.67% | 7.6M | 108분 |

> **최고 성능: LSTM + Temporal Diff (F1 = 0.9430)**
> 센서값의 시간 변화율(Δsensor)을 입력에 추가하는 것만으로 베이스라인 대비 **+2.0%** 향상. 파라미터 증가 없음.

## 3. 핵심 발견

1. **센서 변화율이 가장 중요한 피처.** 센서 절대값보다 시간에 따른 변화량(Δ)이 이상상태 판별에 결정적 역할. 특히 Normal↔Mild 경계 구분에서 효과적.

2. **복잡한 모델이 반드시 좋지 않음.** 10.8M 파라미터의 Transformer 기반 CATFT보다, 2.8M의 LSTM + Temporal Diff가 F1 +1.8% 높음. 현재 데이터 규모(9,313 학습 윈도우)에서는 경량 모델이 유리.

3. **중증 이상상태 100% 감지.** 작업자 안전에 가장 중요한 Severe 상태를 놓치지 않음. 전류(CT) 센서의 급격한 변화가 결정적 단서.
