# 연구노트 #08: 모델 개선 리서치

**작성일:** 2026-04-08
**프로젝트:** 제조공장 멀티모달 센서 기반 이상상태 예측 AI

---

## 1. 리서치 목적

현재 최고 모델(V2, F1=0.9430)의 핵심 약점인 **Normal↔Mild 혼동 45건**을 줄이기 위한 최신 방법론 조사. 우리 데이터(8채널 센서 + 열화상, 9,313 학습 윈도우)에 적용 가능한 것 위주로 선별.

## 3. 가장 효과적인 조합 (추천)

기존 V2 모델에 Tier 1 세 가지를 동시에 적용:

```
V2+ 모델:
  센서 (B,30,8)
    → Multi-Scale Temporal Diff (lag=1,5,10) → (B,30,32)
    → LSTM Encoder → (B,128)
    → SE Channel Attention → (B,128)

  열화상 (B,30,120,160) → 3-layer CNN → (B,128)

  Fusion → Classifier (4-class)

  Loss = 0.7 × CrossEntropy + 0.3 × SupConLoss
```

**변경점:**
- 입력: 8ch → 32ch (원본 8 + delta_1 8 + delta_5 8 + delta_10 8)
- 손실함수: CE → CE + SupCon
- 센서 인코더 뒤에 SE-block 추가
- 파라미터 증가: 2.8M → ~3.0M (미미)

## 4. 각 방법이 Normal↔Mild 문제를 해결하는 원리

| 방법 | 왜 도움이 되는가 |
|------|----------------|
| Multi-Scale Diff | NTC 4°C 차이가 lag-1에서는 작지만, lag-10에서 누적되면 뚜렷한 신호 |
| SupCon Loss | 임베딩 공간에서 Normal/Mild 클러스터를 명시적으로 분리 강제 |
| Channel Attention | Normal/Mild 구분 시 NTC+CT 채널에 가중치 높이고 PM 채널 낮춤 |
