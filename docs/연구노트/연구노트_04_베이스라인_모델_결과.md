## 3. 분석

### 주요 발견
1. **Severe (State 3) 감지 우수**: F1=0.96, Recall=0.98 → 66개 중 65개 정확 감지. 작업자 안전에 가장 중요한 중증 상태를 거의 놓치지 않음.
2. **Normal ↔ Mild 혼동**: Normal 520개 중 39개를 Mild로 오분류 (7.5%). 이 두 상태 간 센서값 차이가 상대적으로 작기 때문 (NTC: 27°C vs 31°C).
3. **Moderate 높은 성능**: F1=0.94로 안정적. 중도 열화 감지 능력 양호.
4. **클래스 가중치 효과**: State 3이 8%밖에 안 되지만 F1=0.96 달성 → WeightedRandomSampler + class-weighted loss가 효과적.

### 학습 곡선 특징
- Epoch 1-9: 빠른 수렴 (F1: 0.75 → 0.91)
- Epoch 14: LR 0.001 → 0.0005 감소 → val F1 추가 개선
- Epoch 18: Best val F1 = 0.9235
- 과적합 조짐: train F1(0.95) vs val F1(0.92) 갭 존재하나 심하지 않음

### 에폭당 학습 시간
- ~37초/에폭 (GPU 1, RTX 6000)
- 총 학습 시간: ~12.5분

1. **Normal ↔ Mild 구분 강화**: 센서 간 상관관계를 포착하는 Cross-Attention 도입
2. **Temporal fusion 개선**: 현재 broadcast+mean 방식 → Transformer 기반 시간축 정렬
3. **열화상 시퀀스 활용**: 현재 프레임 독립 처리 → 비디오 수준 시간적 변화 학습
