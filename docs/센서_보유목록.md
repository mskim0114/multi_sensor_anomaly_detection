# 보유 센서 목록

이 파일은 Jetson Orin Nano 실제 센서 연결 작업을 위해 사용자가 보유한 센서와 연결 메모를 기록한다.

## 확정된 보유 센서

| 구분 | 센서 | 모델/사양 | 프로젝트 입력 채널 | 연결 방식 메모 |
| --- | --- | --- | --- | --- |
| 미세먼지 | Sensirion SPS30 | PM1.0/PM2.5/PM4.0/PM10, I2C/UART, 5V | PM1.0, PM2.5, PM10 | I2C 권장. 주소 0x69. SEL을 GND에 연결하면 I2C 모드. 상세: `docs/SPS30_Jetson_I2C_연결.md` |
| 온도 | 에폭시타입 NTC 서미스터 프로브 | NTC 10K, B=3950 | NTC | 아날로그 센서. Jetson 직결 불가. 10k 기준 저항 전압분배 + ADS1115 ADC 필요. |

## 보유 부품

| 부품 | 사양 | 용도 메모 |
| --- | --- | --- |
| ADS1115 ADC 모듈 | 16-bit, 4채널, 2개 보유 | NTC 및 4-20mA 전류 센서 전압 변환값 측정. 5개 아날로그 채널(NTC + CT1~CT4)을 모두 처리 가능하다. |
| 저항 | 10kΩ | NTC 10K 전압분배 기준 저항으로 사용. 가능하면 1% 이상 정밀도 권장. |
| 저항 | 33Ω | 기존 수동 CT burden 회로 후보값. DHS20P400A-CL420은 4-20mA 출력이라 주 shunt로는 100Ω 쪽이 더 적합하다. 33Ω을 쓰면 4-20mA가 0.132~0.660V가 되어 해상도가 낮아진다. |
| 커패시터 | 16V 10uF | ADC 입력/전원 필터링 후보. 실제 배선 시 위치를 정해야 하며, 4-20mA 루프에 무작정 병렬 연결하지 않는다. |

## 현재 모델 센서 채널 순서

```text
[NTC, PM1.0, PM2.5, PM10, CT1, CT2, CT3, CT4]
```

## SPS30 연결 메모

- 데이터시트와 Sensirion I2C 드라이버 기준 연결 문서: `docs/SPS30_Jetson_I2C_연결.md`
- 전원은 5V, I2C 신호 풀업은 Jetson 보호를 위해 3.3V 기준으로 둔다.
- `SEL`은 센서 전원 인가 시점부터 GND에 연결되어 있어야 I2C 모드로 시작한다.
- I2C 주소는 `0x69`이며, ADS1115 기본 주소대 `0x48`/`0x49`와 충돌하지 않는다.

## NTC 10K 3950 연결 메모

- 극성 없음.
- 일반적으로 25°C에서 10kΩ, B coefficient 3950K 기준으로 온도 변환한다.
- Jetson Orin Nano에는 아날로그 입력이 없으므로 ADS1115 같은 ADC를 사용한다.
- 권장 시작 회로: 3.3V 기준 전압분배, 10kΩ 1% 고정 저항, ADS1115는 3.3V 구동.
- 실제 연결 전에는 보유한 ADS1115 모듈의 풀업/전원 구성을 확인해야 한다.

## DHS20P400A-CL420 전류 센서 연결 메모

- 400A급 AC/DC 전류 트랜스듀서이며 출력은 4-20mA current loop다.
- 별도 20~30V 전원이 필요하다. 보통 24V 전원으로 구동한다.
- 데이터시트 기준 2-wire 4-20mA 출력이며, 24V 전원에서 최대 부하 저항은 300Ω이다.
- Jetson/ADS1115에 전류 루프 출력을 직접 넣지 않는다.
- 권장 시작 변환: 100Ω 0.1% shunt resistor를 사용해 4-20mA를 0.4~2.0V로 변환한다.
- 변환식:

```text
I_sensor_mA = V_shunt / R_shunt * 1000
Current_A = (I_sensor_mA - 4.0) * 25.0
```

- 100Ω 기준:
  - 0A -> 4mA -> 0.4V
  - 400A -> 20mA -> 2.0V
- ADS1115는 3.3V 구동, single-ended 입력, PGA는 ±2.048V 또는 여유 있게 ±4.096V 설정을 검토한다.
- 실제 배선 전에는 센서 본체 라벨/데이터시트의 단자명을 확인해야 한다. 4-20mA 센서는 배선 방식이 2-wire/3-wire/4-wire에 따라 달라질 수 있다.
- 4채널을 동시에 쓸 경우 100Ω 정밀 저항 4개를 추가 구매하는 편이 좋다. 현재 보유한 33Ω은 동작 확인용으로는 가능하지만 ADC 해상도가 낮다.

## PureThermal Mini Pro JST-SR + FLIR Lepton 3.5 연결 메모

- Lepton 3.5가 포함된 PureThermal Mini Pro는 plug-and-play UVC thermal webcam으로 동작할 수 있다.
- 해상도는 160x120이고, 프로젝트 thermal 입력 120x160과 축/shape만 맞추면 된다.
- 우선 연결 방식은 Jetson USB다. 연결 후 `/dev/video*`, `v4l2-ctl --list-devices`, OpenCV 캡처 순서로 검증한다.
- radiometric 온도값을 쓰려면 UVC pixel format과 GetThermal/PureThermal 펌웨어 모드를 확인해야 한다.

### 2026-06-22 USB 연결 확인

- Jetson USB 목록에서 PureThermal/UVC 카메라는 아직 인식되지 않았다.
- `/dev/video*` 및 `/sys/class/video4linux/*` 장치가 생성되지 않았다.
- 현재 보이는 관련 USB 장치는 `067b:2303 Prolific PL2303 USB-Serial Controller`이며, 카메라가 아니라 USB-serial 계열 장치로 보인다.
- PureThermal Mini Pro는 정상 연결 시 UVC video 장치로 잡혀야 하므로 케이블/포트/보드 전원 상태를 다시 확인해야 한다.
- 사용자는 JST-SR to USB 케이블을 본체 USB에 직접 연결했다고 확인했다. 그래도 USB descriptor는 `Prolific Technology Inc. USB-Serial Controller`로만 보이며, Video Class interface가 없다.
- Jetson에는 `uvcvideo` 커널 모듈이 설치되어 있다. 따라서 현재 문제는 UVC 드라이버 부재보다는 케이블/보드/포트/펌웨어 모드 쪽으로 본다.
- 재연결 후에도 동일하게 `067b:2303 Prolific PL2303 USB-Serial Controller`로 인식되며 `/dev/video*`는 생성되지 않았다. 현재 케이블은 USB D+/D-를 PureThermal UVC 포트에 직접 연결하는 케이블이 아니라 USB-serial 변환 케이블일 가능성이 높다.
- 사용자가 확인한 케이블 핀은 `GND/VCC/TXD/RXD`이고, PureThermal 쪽 USB 핀은 `VCC/D-/D+/GND`다. `TXD/RXD`는 UART 신호라서 핀 순서만 바꿔도 USB `D-/D+` 신호가 되지 않는다. 이 케이블은 PureThermal UVC 연결에 사용하지 않는다.
- 필요한 케이블은 수동 USB 배선 케이블이다: `USB 5V -> VCC`, `USB D- -> D-`, `USB D+ -> D+`, `USB GND -> GND`.
- USB-serial 보드를 제거하고 재배선한 뒤에는 Jetson에서 새 USB 장치가 전혀 인식되지 않았다. `/dev/video*`도 없고 `lsusb`에도 PureThermal/PL2303 모두 없다. 이 상태는 VBUS/GND 미공급, D+/D- 오배선, JST 방향 오류, 접촉 불량 중 하나를 우선 의심한다.

### 2026-06-22 연결 성공

- PureThermal이 `1e4e:0100 Cubeternet WebCam` / `GroupGets PureThermal (fw:v1.3.0)`로 인식됐다.
- UVC driver `uvcvideo`가 붙었고 `/dev/video0`, `/dev/video1`이 생성됐다.
- GStreamer 확인 포맷:
  - `UYVY 160x120 9fps`
  - `GRAY16_LE 160x120 9fps`
  - `GRAY16_LE 160x122 9fps`
  - `GRAY8 160x120 9fps`
  - `RGB16 160x120 9fps`
  - `BGR 160x120 9fps`
- `/dev/video0`에서 `GRAY16_LE 160x120` 한 프레임 캡처 성공:
  - 파일: `jetson_deploy/results/camera/purethermal_frame_160x120_gray16.raw`
  - 크기: 38400 bytes = 160 x 120 x 2
  - pixel raw range: 29986~30996, mean 30122.39
  - raw 값이 centi-Kelvin이면 섭씨 약 26.71~36.81°C, 평균 약 28.07°C
