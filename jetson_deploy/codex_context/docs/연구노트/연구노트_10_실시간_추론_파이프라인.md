## 1. 구현 내용

### V2+ ONNX 변환 결과

| 항목 | 값 |
|------|-----|
| 모델 크기 | 10.9 MB |
| 정확도 손실 | 없음 (1157/1157 일치) |

### 추론 속도

| Backend | 속도 (ms) | 1초 목표 대비 |
|---------|----------|:----------:|
| PyTorch GPU | 1.18 | 847배 여유 |
| ONNX GPU | 2.61 | 383배 여유 |
| ONNX CPU | 7.27 | 137배 여유 |
| **Jetson 추정** | **~5** | **200배 여유** |

### 실시간 파이프라인 아키텍처

```
[센서] → SensorCollector → DataBuffer (30-step 슬라이딩 윈도우)
                                ↓
                         Preprocessor (Z-score + MinMax 정규화)
                                ↓
                         InferenceEngine (ONNX Runtime)
                                ↓
                         AlertManager
                           ├── none: 정상
                           ├── warning: 주의 관찰
                           └── danger: 즉시 점검 (시각/청각 알림)
```

### 알림 규칙

| 조건 | 알림 |
|------|------|
| Severe + 높은 확신도 (>50%) | **DANGER** |
| Severe 3회 연속 | **DANGER** |
| Moderate + 높은 확신도 (>70%) | WARNING |
| Moderate 5회 연속 | WARNING |

### 시뮬레이션 테스트 결과
- Normal → Severe 전이 시 **즉시 DANGER 알림 발생** 확인
- 추론 로그 JSON 자동 저장
