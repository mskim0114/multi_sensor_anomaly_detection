# 연구노트 #07: 모델 경량화 및 배포 준비

**작성일:** 2026-04-08
**프로젝트:** 제조공장 멀티모달 센서 기반 이상상태 예측 AI

## 1. 목적

최고 성능 모델(V2: LSTM+TemporalDiff)을 Jetson Orin Nano 배포용으로 ONNX 변환하고, 추론 속도 및 정확도 보존을 검증.

## 2. ONNX 변환

| 항목 | 값 |
|------|-----|
| 원본 모델 | V2 (LSTM+TemporalDiff), PyTorch |
| ONNX opset | 17 |
| 모델 크기 | **10.8 MB** |
| PyTorch vs ONNX 출력 차이 | **0.000007** (무시 가능) |
| Dynamic batch | 지원 |

## 3. 추론 속도 벤치마크

테스트 환경: Quadro RTX 6000, batch=1 (실시간 시뮬레이션), 100회 반복

| Backend | 평균 (ms) | Std | P95 (ms) | 실시간 가능 |
|---------|----------|-----|---------|:----------:|
| **PyTorch GPU** | **1.05** | 0.35 | 1.58 | ✅ |
| **ONNX GPU** | **2.53** | 0.09 | 2.64 | ✅ |
| ONNX CPU | 5.42 | 1.26 | 7.04 | ✅ |
| **Jetson Orin Nano (추정)** | **~4** | - | - | ✅ |

> **목표: 1초(1000ms) 이내 추론 → 모든 백엔드에서 달성.** 가장 느린 ONNX CPU도 5.42ms로 목표 대비 180배 이상 여유.

## 4. 정확도 보존 검증

| Backend | Val Accuracy | Val F1 (macro) | 예측 일치율 |
|---------|-------------|----------------|:----------:|
| PyTorch GPU | 0.9352 | 0.9430 | - |
| ONNX CPU | 0.9352 | 0.9430 | **100%** (1157/1157) |

> **ONNX 변환 후 정확도 손실 없음. 1157개 전체 예측이 완벽히 일치.**
