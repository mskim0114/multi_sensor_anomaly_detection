# PC3 / 제한된 온라인 적응

- **상태:** `IDEA` — PC1·PC2 기준선 확보 전에는 착수하지 않는다.
- **가설 ID:** `FIELD-HC`
- **산업 문제와 필요한 의사결정:** 설비·계절·작업 프로그램이 바뀌면 정상 기준이 이동한다.
  재교정에 사람이 얼마나 개입해야 하는지 결정해야 한다.
- **한 문장의 핵심 주장 (검증 상태 표시):** *가설, 미검증* — 정상 운전 변화에는 빠르게 적응하면서
  실제 이상이 지속될 때 검출 능력이 사라지지 않는 제한적 적응이 가능하다.
- **가장 가까운 선행 연구와 차이:** Fast Weight Attention 계열은 참고 후보이나 주요 검증이 산업
  열화 진단이 아니다. 비교 대상에 **단순 EMA / NLMS / RLS / 작은 recurrent memory**를 반드시
  포함한다. 비교표 미작성.
- **기존 방법이 실패하는 구체적 조건:** 모든 센서 변화를 메모리에 쓰는 모델은 고장까지 정상화한다.
  "예측 오차가 줄었다"만으로 성공 판정하지 않는다.
- **제안 방법의 최소 구성:** 고정 참조 모델과 적응 메모리를 **분리**하고 업데이트 허용 조건을
  명시한다. 본체 가중치 재학습과 forward-pass memory 갱신을 구분한다.
- **필요 데이터와 현재 확보 수준:**
  - 장시간 stream: **없음** (최장 360초)
  - 정상 조건 변화: 없음
  - 진행성 이상: 없음
  - 정상 변화와 이상 동시 발생: 없음
  - 복구 후 재운전: 없음
- **필수 기준선·ablation·반례:** 고정 모델 / 단순 EMA 또는 온라인 선형 / 무조건 적응 /
  제한 적응. 현재 표본으로 **평가한 뒤 업데이트**하는 순서를 지켜 같은 표본에 대한 적응 이득을
  성능으로 세지 않는다.
- **주장별 연결된 실험 ID:** 미등록.
- **확보된 그림/표:** 없음.
- **기각·축소 조건:** 초기에는 탐지하지만 적응 후 지속 이상을 놓친다. 또는 단순 적응 기준선
  대비 의미 있는 이득이 없다. 이상 점수 감소만으로 정상 복귀를 판단하지 않는다.
- **다른 후보와 통합 가능성:** 독립 질문이며 증거가 충분해질 때까지 분리 유지.
- **현재 상태와 다음 승격 조건:** `IDEA`. `DESIGNED` 승격 조건 = PC1·PC2에서 고정 모델 기준선이
  확보되고 장시간 stream 수집 계획이 확정.
