### 4.3 핵심 패턴 해석

1. **온도(NTC):** 열화 단계와 **선형적 상관관계**. 정상(27°C) → 중증(51°C), 약 24°C 상승. 가장 안정적인 지표.
2. **미세먼지(PM):** State 0→2까지 점진적 증가 후 **State 2~3에서 포화**. 초기 열화 감지에 유용하나 중증 구분에는 한계.
3. **전류(CT):** State 0~1은 비슷하다가 **State 2~3에서 급격히 증가**. 특히 State 3에서 폭발적 증가. 중증 열화 감지의 핵심 지표.

**모델링 시사점:**
- NTC는 전 단계에서 유용한 **범용 지표**
- PM은 **초기 이상 감지** (State 0→1 전이)에 유용
- CT는 **중증 이상 감지** (State 2→3 전이)에 결정적
- 3종 이상상태와의 매핑: 열적 과부하(NTC 주도), 탄화/연기(PM 주도), 전기/기계 결함(CT 주도)이 데이터로 뒷받침됨

## 8. 데이터 품질 평가

**장점:**
- 대규모 (111,870 샘플), 논문 수준의 실험에 충분
- 장비 단위 train/val 분리 → 일반화 성능 평가 가능
- 상태별 센서 패턴이 명확 → 모델 학습 가능성 높음
- 모든 BIN 파일이 동일 shape (120×160) → 전처리 일관성

**주의사항:**
- State 3 비율 ~8% → 클래스 불균형 대응 필요 (Focal Loss, oversampling 등)
- 전류 센서 스케일 편차 큼 → 센서별 정규화 필수
- PM 센서 State 2~3 포화 현상 → 단독으로는 중증 구분 어려움
- CSV가 1행 데이터 → 시계열 구성 시 파일 단위 로딩 필요 (I/O 병목 가능)
